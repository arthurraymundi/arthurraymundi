## 🚀 Projetos em destaque

### 🧠 [Well AI](https://github.com/nickezinho/well-ai) · Assistente de bem-estar com IA
> `React` `TypeScript` `FastAPI` `PostgreSQL + pgvector` `OpenAI` `Docker`

Assistente conversacional de bem-estar com chat autenticado, histórico e memória persistente controlada pelo usuário, análise nutricional de fotos de refeições e respostas baseadas em guias oficiais de saúde (RAG).

- 🔐 Autenticação por sessão, rate limiting e controle de custo por usuário
- 🤖 RAG com pgvector, modelos de fallback e validação de respostas
- 🐳 Deploy em produção com Docker Compose, HTTPS e backups

<br/>

### 🥗 [MGourmet](https://github.com/arthurraymundi/MGourmet) · E-commerce de marmitas fitness
> `React` `TypeScript` `FastAPI` `SQLAlchemy` `PostgreSQL` `Docker`

Sistema web para uma empresa real de marmitas congeladas fitness em Jundiaí/SP, com catálogo, carrinho, checkout integrado ao WhatsApp e painel administrativo.

- 🛒 Catálogo, carrinho e checkout responsivos
- 🧑‍💼 Painel admin com CRUD de produtos e gestão de pedidos
- 🔑 Autenticação JWT e infraestrutura com Docker Compose

<br/>

### 📋 [PI II · Time 22](https://github.com/LuisTravaglini/PI_II_TIME_22) · Acompanhamento de demandas de software
> `Node.js` `TypeScript` `Bootstrap` `MySQL` `GitHub Projects`

Projeto Integrador II (PUC-Campinas): sistema para organizar projetos e controlar tarefas, defeitos, melhorias e documentação, desenvolvido em equipe com metodologia ágil.

<br/>

### 🗳️ [Urna Eletrônica](https://github.com/LuisTravaglini/ES-PI1-2026-T2-G01) · Projeto Integrador I
> `Python` `MySQL`

Backend de uma urna eletrônica fictícia com gestão de candidatos e eleitores, votação, auditoria e estatísticas da eleição.
